# 连接 MCP 客户端

这是当前开发分支的预览功能，尚未完成完整原生应用与各平台打包验收。已有正式安装包不保证包含本页所述命令。

## 选择一种运行方式

### 在桌面应用中使用

1. 在「系统设置 → 账号与连接」完成账号配置并保存。
2. 打开「高级与实验」，启用 MCP、设置端口，再保存设置。
3. 查看「MCP 运行状态」中的实际监听地址，或复制下方连接说明，填入支持 **Streamable HTTP** 的 MCP 客户端。
4. 保持 Canvas Helper 运行。连接后可先调用 `list_courses`，再查询课程、文件或作业。

表单中修改但未保存的端口不会改变服务。状态面板是最近一次读取的快照，可以手动刷新；它不替代网络连接或账号有效性检查。连接说明按表单端口生成，填写前请与实际监听地址核对。

### 不打开窗口，仅运行服务

先在桌面应用中保存账号配置，然后**完全退出桌面应用**。在终端运行应用的可执行文件：

```sh
"/path/to/SJTU Canvas Helper" --mcp
```

启动成功后，终端会显示连接地址。使用已保存的端口；如需临时换端口：

```sh
"/path/to/SJTU Canvas Helper" --mcp --mcp-port 3101
```

查看帮助不会打开窗口、读取账号或启动服务：

```sh
"/path/to/SJTU Canvas Helper" --mcp --help
```

`--mcp --help` 和 `--mcp -h` 优先显示帮助，其余参数不会执行。端口范围为 1–65535。端口参数只影响本次进程，不修改已保存设置。

macOS 请调用应用包内的实际可执行文件，例如：

```sh
"/Applications/SJTU Canvas Helper.app/Contents/MacOS/SJTU Canvas Helper" --mcp
```

这不会安装系统服务或开机启动项。终端进程必须持续运行；在 Unix 上用 Ctrl+C 或 SIGTERM 请求关闭。清理 MCP 和播放代理共用 25 秒期限，随后运行时最多再等待 2 秒。超时或清理失败不会被报告为成功。强制结束进程无法保证优雅清理，已发出的远程请求也不能撤回。

Windows 发行程序仍使用 GUI 子系统，控制台输出、Ctrl+C/Ctrl+Break 和各平台打包行为尚未验证。不要把关闭终端视为已确认的优雅退出。

## 客户端配置示例

默认端口为 3100 时，连接地址是 `http://127.0.0.1:3100/mcp`，不是 stdio 命令。若实际监听端口不同，请相应替换。

通用配置结构如下，具体字段以客户端文档为准：

```json
{
  "mcpServers": {
    "sjtu-canvas": { "url": "http://127.0.0.1:3100/mcp" }
  }
}
```

OpenCode 可合并到现有配置的 `mcp` 字段：

```json
{
  "mcp": {
    "sjtu-canvas": {
      "type": "remote",
      "url": "http://127.0.0.1:3100/mcp",
      "enabled": true
    }
  }
}
```

## 常见问题

- **提示配置正在使用：** 完全退出另一个 Canvas Helper 进程。换 MCP 端口不能绕过配置目录的独占锁，也不要删除锁文件。
- **端口已占用：** 停止占用该端口的程序，或使用 `--mcp-port` 选择另一个有效端口，并更新客户端地址。
- **客户端连不上：** 确认进程仍运行、监听地址与客户端一致，并使用 Streamable HTTP。启用开关和旧状态快照不等于连接成功。
- **参数被拒绝：** 运行 `--mcp --help` 查看用法。未知或重复参数不会被静默忽略。
- **文件解释暂时不可用：** GUI MCP 每次只接受一个文件解释任务。等待当前任务结束再试；取消等待后，已经开始的解析可能仍需时间退出。无界面模式不提供文件解释。

## 数据与权限

- 无界面模式禁用 `chat`、`explain_file` 和 `test_token`，没有 AI 开启参数。
- 桌面 GUI MCP 保留现有 AI 工具。调用可能将内容发送到配置的外部模型服务并产生费用，请在客户端确认授权和模型设置。
- 本机监听不是身份鉴权。同机其他进程可能通过它访问 Canvas 数据；仅在可信设备上使用，不要通过代理公开到网络。
- GUI 与无界面进程不能同时使用同一配置目录。无界面进程使用启动时的账号设置；更换账号或配置后应停止并重启。
- MCP 文件解释只接受课程 ID 和文件 ID，下载地址从 Canvas 元数据解析。文件限制为 20 MiB，解析后文本限制为 128000 个 Unicode 字符，DOCX 表格与嵌套表格文字也计入限制。仅允许受支持的 Canvas HTTPS 主机，因此合法的外部 CDN 文件也可能被拒绝。
- 文本限制在解析之后执行，不是文档解析沙箱。阻塞解析不能被异步超时强行终止。
